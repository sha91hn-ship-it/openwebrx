# OpenWebRX profile-access extension

Contains the staged source edits and checks for anonymous receiver profile access, with the selected FM and airband profiles kept protected. `apply.py` installs staged files into the OpenWebRX Python package, updates the generic settings file, and restarts the service. Review the staged code for your OpenWebRX version before applying it.

All local account names and machine paths in this export use the placeholder `user`. Do not commit server settings, user databases, API keys, bookmarks, or recordings.
